# Trust-Aware Explainable AI for Abnormal Tooth Detection and Diagnosis in Panoramic Dental X-Rays

Two-stage pipeline: YOLO (abnormal-region localization) → Swin-Tiny (diagnosis classification) → dual XAI (Grad-CAM++ / Integrated Gradients) → calibration → annotated report.

See `docs/project_findings_report.md` for full methodology, dataset analysis, and design decision log.

## Project Structure

```
.
├── config.py                  # single source of truth for all paths (Kaggle vs local)
├── requirements.txt
├── scripts/
│   ├── 00_split_dataset.py            # stratified multi-label train/val/test split
│   ├── 01_coco_to_yolo_labels.py      # YOLO localization labels (single-class)
│   ├── 02_crop_generation.py          # ground-truth tooth crops for Swin-Tiny
│   ├── 03_train_yolo.py               # YOLOv8 vs YOLOv11 comparison  (upcoming)
│   ├── 04_train_swin.py               # Swin-Tiny diagnosis classifier (upcoming)
│   ├── 05_xai_gradcam_ig.py           # Grad-CAM++ / Integrated Gradients (upcoming)
│   └── 06_calibration_eval.py         # ECE, reliability diagrams (upcoming)
├── data/                        # NOT committed -- see Setup below
├── outputs/                     # NOT committed (except split_report.txt) -- regenerated by scripts
└── docs/
    └── project_findings_report.md
```

## Setup (local)

1. `pip install -r requirements.txt`
2. Download the dataset:
   ```
   kaggle datasets download truthisneverlinear/dentex-challenge-2023 -p data/dentex-challenge-2023 --unzip
   ```
3. Set the environment variable so `config.py` resolves local paths:
   ```
   export DENTEX_ENV=local        # Windows (PowerShell): $env:DENTEX_ENV="local"
   ```
4. Run the pipeline in order:
   ```
   python scripts/00_split_dataset.py
   python scripts/01_coco_to_yolo_labels.py
   python scripts/02_crop_generation.py
   ```

## Setup (Kaggle)

`config.py` defaults to Kaggle paths automatically (`DENTEX_ENV` unset = `"kaggle"`) — no changes needed, just attach the `truthisneverlinear/dentex-challenge-2023` dataset to your notebook and run the scripts in order.

## Reproducibility notes

- Dataset split uses a fixed seed (`SEED = 42` in `00_split_dataset.py`) — re-running produces identical splits.
- YOLO detects abnormal-candidate regions only (single class); diagnosis classification happens downstream in Swin-Tiny.
- Swin-Tiny trains on ground-truth crops; full pipeline evaluation uses YOLO's *predicted* crops (see `docs/project_findings_report.md` §4.2).
